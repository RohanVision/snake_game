## Snake_App

# A Simple Snake app build using HTML, CSS and JavaScript. Instead of using Canvas I used CSS Grid for snake board.
## The goal is to collect as many as food and grow the snake.
## if user hit the snakebody or went outside of the grid the game is over and alert will pop-up.
## To restart the game press OK
